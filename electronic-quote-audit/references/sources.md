# 术语与来源边界

公开来源由主理人于2026-10-24核验；产品实现与合成样例原创，无第三方技能或产品源码复制。来源只用于术语校准，不授权转换任何真实客户报价条件。

- [DigiKey：How to Read a DigiKey Quote](https://www.digikey.com/en/help-support/place-an-order/how-to-read-a-digi-key-quote)：Minimum Release是享受所报价的最低购买要求；Package Quantity是厂商标准包装量。BAL/ARO/厂商交期有关分销库存到达估计，不能当客户收货承诺。Pricing Valid Through表示截至期限。实现因此分开保存release、MOQ、倍数与包装，并按客户明确单位/条件计算。
- [ERPNext：Supplier Quotation](https://docs.frappe.io/erpnext/supplier-quotation)：已有供应商报价与比较工作流，价格需要数量、币种、单位、税费、运费和交期背景；本技能不声称发明比价。
- [Odoo 19：Calls for tenders](https://www.odoo.com/documentation/19.0/applications/inventory_and_mrp/purchase/manage_deals/calls_for_tenders.html)：已有替代RFQ产品/订单行比较能力。任何版本、托管、实施费用需另核实，不能因存在文档推断服务免费。
- [ERPNext 官方仓库](https://github.com/frappe/erpnext)：开源ERP可作为方案对照；自托管与支持仍有资源成本。本技能只证明本地核对与可追溯计算，不作商业唯一性或省钱保证。

本技能不调用上述网址；运行只读取用户指定本地文件，不联网查询价格、汇率或发送报价。
